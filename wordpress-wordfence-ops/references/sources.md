# Sources for the WordPress Wordfence Ops skill

Research compiled 7 Nov 2026 for the agent-ops-skills repo. Use for facts, links, and capability lists. Write original procedure text — never paste documentation text verbatim.

## Official foundation

- Wordfence Help — Scan — www.wordfence.com/help/scan — what a scan covers (malicious code, backdoors, shells, malicious URLs, infection patterns), manual vs scheduled scans, scanning of core/plugin/theme options for dangerous URLs and admin users created outside WordPress.
- Wordfence Help — Scan Results — www.wordfence.com/help/scan/scan-results — severity levels: Critical (act immediately), High (soon), Medium (aware, optional action), Low (safe to ignore); actions per result; ignore rules.
- Wordfence Help — Wordfence API — www.wordfence.com/help/advanced/wordfence-api — the programmatic API surface (premium/license-key based) for Central and related integrations.
- Wordfence Help index — www.wordfence.com/help — firewall (WAF basic/optimized modes, learning mode), blocking, country blocking, two-factor authentication, lockouts.

## Context

- Wordfence is the most-installed WordPress security plugin (4M+ active installs). This skill feeds the repo's maintenance-ops health pass with a security section and keeps remediation approval-gated like the rest of the set.
